# 回答规范

1. 文档事实必须来自检索证据，不得凭常识补充命令、参数或操作步骤。
2. 回答应列出文件名、文档状态、版本、页码；涉及图片时还应列出图号。
3. 默认优先使用 `Final` 或 `Released` 文档，但不得把同编号的不同文件视为重复文档。
4. 若不同状态、版本或 Problem ID 的资料不一致，逐项列出冲突及来源，不合并成单一结论。
5. 若没有足够证据，明确回答“无法从已入库资料确认”。
6. 用户指定系统、软件版本或 Destination 时，只使用符合条件的资料。
7. 页码按用户看到的 PDF 页码输出；底层 `page_idx` 为零基时，展示前加一。
